# ⏱️ React Timer Challenge

A reflex-based **React game** where you try to stop the timer as close as possible _before_ it reaches the target time.  
The closer you stop, the higher your score — but if the timer reaches the target, you lose ❌

---

## 🎮 Features

- Select a target time: **1, 5, 10, or 15 seconds**.
- ▶️ Start the timer with a button click.
- ✋ Stop the timer anytime before the target.
- 📊 Instant feedback after each attempt:
  - **Score** → higher if you stopped closer.
  - **Target time** → what you aimed for.
  - **Time left** → how close you were.
